# STATUS Dental Center — сайт стоматологии в Алматы

Новая версия сайта клиники STATUS Dental Center. Одностраничный сайт на Next.js
с реальными данными клиники: услуги, врачи, цены, клинические случаи, отзывы и
контакты.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/import?s=https%3A%2F%2Fgithub.com%2Fblistrick%2F-)

## Стек

| Технология   | Версия | Зачем                                         |
| ------------ | ------ | --------------------------------------------- |
| Next.js      | 16     | App Router, оптимизация изображений, метаданные |
| React        | 19     | UI                                            |
| TypeScript   | 5      | Типизация данных клиники и компонентов        |
| Tailwind CSS | 4      | Дизайн-токены и утилиты                       |
| lucide-react | —      | Иконки                                        |

Анимации сделаны на CSS и `IntersectionObserver` без дополнительных библиотек,
поэтому JavaScript-бандл остаётся небольшим.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production-сборка
npm run start   # запуск собранного приложения
npm run lint    # ESLint
```

## Деплой

Проект не требует переменных окружения и дополнительной настройки сборки.

1. Откройте [vercel.com/new](https://vercel.com/new) и импортируйте репозиторий.
2. В поле **Project Name** укажите, например, `status-dental-center`. Имя
   репозитория состоит из одного символа, и Vercel такое имя проекта не примет.
3. Framework Preset определится как Next.js автоматически, менять ничего не нужно.

После подключения репозитория каждая ветка и каждый pull request получают
собственный preview-адрес, который удобно показывать заказчику до того, как
изменения попадут в `main`.

Подойдёт любой хостинг с поддержкой Node.js: сборка запускается командой
`npm run build`, запуск — `npm run start`. Полностью статический хостинг не
подойдёт, потому что маршрут `/api/lead` принимает заявки из калькулятора.

## Структура

```
src/
  app/                 layout, метаданные, robots, sitemap, иконки, OG-картинка
    api/lead/route.ts  приём заявок из калькулятора стоимости
  components/
    layout/            Header, Footer, WhatsAppButton, MobileActionBar
    sections/          Hero, TrustSection, Services, WhyStatus, Technology,
                       Cases, Doctors, Prices, Calculator, Reviews, Faq, Contact
    seo/               JSON-LD разметка Dentist и FAQPage
    ui/                Reveal, SectionHeading, Counter, Modal, BeforeAfter, Logo
  data/                контент: клиника, услуги, врачи, цены, кейсы, отзывы, FAQ
  lib/                 утилиты
public/images/         фотографии, портреты врачей, кейсы до/после, карта
```

Весь текстовый и числовой контент вынесен в `src/data`. Чтобы обновить цену,
врача или кейс, достаточно отредактировать соответствующий файл — верстку
трогать не нужно.

## Контент

Все данные взяты с действующего сайта клиники: телефоны, адрес, часы работы,
прайс, состав команды, клинические случаи и отзывы. Ничего не придумано.
Гарантии и сроки указаны только там, где клиника указала их для конкретного
случая.

Фотографии «до/после» на исходном сайте были одним кадром: состояние «до»
сверху, «после» снизу. Для слайдера сравнения каждый кадр разрезан на два файла
с общим слагом (`<slug>-before.webp` и `<slug>-after.webp`). Часть кадров уже
содержит впечатанные подписи «ДО»/«ПОСЛЕ» — такие случаи помечены полем
`bakedLabels`, чтобы интерфейс не рисовал вторую пару подписей поверх.

Карта в разделе контактов — статичное изображение, собранное из тайлов
OpenStreetMap и приведённое к палитре сайта. Внешних запросов на карту нет,
атрибуция указана на самой карте, клик ведёт на карточку клиники в 2ГИС.

## Заявки из калькулятора

Форма отправляет `POST /api/lead`. Сейчас обработчик проверяет заявку и пишет её
в лог сервера — в файле `src/app/api/lead/route.ts` помечено `TODO`, куда
подставить реальную интеграцию (CRM, Telegram-бот или почта) и через какие
переменные окружения передать доступы. Если запрос не прошёл, экран «Спасибо»
всё равно предлагает WhatsApp с заполненной заявкой и звонок, поэтому обращение
не теряется.

## Доступность и SEO

- Семантическая разметка, один `h1`, `alt` у всех изображений, skip-link.
- Модальные окна с ловушкой фокуса, закрытием по Escape и блокировкой прокрутки.
- Слайдер «до/после» управляется с клавиатуры и объявляется как `slider`.
- `prefers-reduced-motion` отключает все анимации.
- JSON-LD `Dentist` и `FAQPage`, Open Graph, Twitter Card, favicon, sitemap,
  robots.
